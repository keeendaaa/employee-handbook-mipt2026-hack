# Данные кейса

## Размещение

- `raw/` — оригинальные PDF, DOCX и XLSX с исходными именами.
- `manifest.json` — локальный реестр загрузки: источник, ID файла, имя, размер, SHA-256 и результат технической проверки.
- `review/` — локальный извлеченный текст, изображения страниц и подробные результаты проверки возможности публикации.

Все три пути исключены из Git. Публичная доступность по ссылке не подтверждает отсутствие конфиденциальных сведений. Не публикуйте исходники и производные данные до подтверждения их статуса.

Локально загружены и технически проверены все 20 файлов, общий размер — 28 469 871 байт. В реестре сохранены контрольные суммы; ошибок загрузки нет. Первичный скрининг публикации выполнен. 13.11.2026 пользователь подтвердил неконфиденциальность материалов и разрешил их передачу на VPS и в Command Code API. Право на перепубликацию исходников в GitHub отдельно не подтверждено. См. [DATA_PUBLICATION.md](../materials/DATA_PUBLICATION.md).

Файлы нужно получить отдельно от этого репозитория. Клонирование Git не загружает локальную базу документов.

## Сверка с заданием

Ожидается 20 файлов: 9 PDF, 8 DOCX, 3 XLSX. Полный перечень приведен в [DOCUMENTS.md](../materials/DOCUMENTS.md).

В предоставленной папке документ D01 называется `Регламент бронирования конц зала.pdf`, тогда как в задании указан `Регламент бронирования концертного зала.pdf`. Это соответствие по перечню; тождественность содержания с отдельным эталонным файлом не проверена. Оригинальное имя не изменяется.

## Границы технической проверки

Проверка загрузки включает размер файла относительно списка Google Drive, SHA-256, сигнатуру PDF либо целостность ZIP-контейнера и XML для DOCX/XLSX. Она не подтверждает полноту извлечения текста, качество OCR, актуальность регламента или правильность ответов системы.

После загрузки требуется отдельная содержательная проверка и индексация. Файлы не отправляются во внешние сервисы обработки.
