# Смена · frontend

Перед использованием UI SDK прочитать `node_modules/@ui-sdk/react/docs/llms.txt` и документацию выбранного компонента. Для нового примитива найти соответствующий раздел `docs/core.md` и прочитать `docs/rendering.md`. Использовать установленный ui-sdk skill, если он доступен.

Источник токенов и компонентов: `design-system/`. `src/design-tokens.css` генерируется из Figma; не менять его вручную. Все цвета используют роли этой системы. `src/foundation.css` — базовый контракт компонентов. Сохранять ширины 390/1024/1440 и проверять новые контейнеры на 320/1920.

Не превращать технические кадры прототипа Figma в компоненты приложения. Шаги берутся только из `answer.steps`, основания — из `citation_ids`. Сохранённый прогресс не означает завершение оформления во внешних системах. Не заменять ошибки API демоответами. Не передавать UI-настройки отображения как системные инструкции RAG.

Проверки: `pnpm build`, `pnpm test`, `pnpm test:e2e`. В E2E используются явно синтетические фикстуры; они проверяют интерфейс и HTTP-контракт, не качество реальных регламентов.

14 ноября2026 пользователь изменил рабочий процесс: дальше работать только с frontend. Не читать и не менять Figma/Local Bridge без нового прямого запроса. Токены из текущего экспорта сохраняются; изменения поведения, стилей и анимаций описывать в локальном frontend/design-system. Не пытаться автоматически догонять Figma по коду.

Анимации интерфейса: существующий Motion for React, общий useUiTransition в src/lib/ui-motion.ts. Короткие150ms, без пружин/декоративного зацикливания; prefers-reduced-motion отключает движение и fade. Логотип из public/brand/mipt-emblem.jpg статичен. В EvidenceCard цитаты без mark и жёлтого фона; выделение появляется только в SourceModal после явного открытия фрагмента.
