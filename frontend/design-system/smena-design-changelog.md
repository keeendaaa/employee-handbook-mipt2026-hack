# Изменения дизайн-системы Смена

## 1.3.0 — 2026-11-14

Причина: исправление навигации, источников, полей и открытия регламентов по обратной связи.

- Граф: круги и тонкие связи, force layout, все реальные узлы, поиск, pan/zoom/fit, перетаскивание, фильтры и полный экран. Подписи учитываются при fit на узких экранах.
- EvidenceCard: закрытые строки с раскрываемой цитатой и действием. Убрана постоянная боковая колонка. Увеличены интервалы текста и действий.
- Устранена двойная внутренняя рамка составных полей; сохранён внешний клавиатурный фокус. Checkbox снимает отметку повторным нажатием без изменения яркости.
- Каталог открывает весь извлечённый текст версии документа. Добавлен read-only API с проверкой корпуса и явными404/409/503.
- Официальный логотип МФТИ; три оригинальные иллюстрации. Заимствованные иллюстрации Notion удалены; источники перечислены в notices и asset manifest.
- Токены не менялись:114 переменных,12 текстовых стилей, экспорт1.2.0 сохранён. Контракт, CSS, manifest и карта состояния синхронизированы с frontend. Нативная Figma1.2.0 пока pending_connection: исходный файл отключён от Local Bridge. Непроведённая проверка автолейаутов не заявляется.
- Production build,7 unit-тестов и22 E2E; ширины320/390/1024/1440/1920. Визуально просмотрены новая задача, источники, чтение документа и граф. Тесты используют синтетические материалы и не отправляют писем.

## 1.2.0 — 2026-11-14

Причина: восстановление основного флоу задачи и реализация frontend по утверждённому макету.

- Описание → декомпозиция → этапы с основаниями → отметки → продолжение → завершение. Добавлены состояния2/4,4/4, «Мои задачи», просмотр точной цитаты и запрос материалов без потери прогресса.
-54 канонических экрана,30 адаптивных примеров; исходные ID01–18 сохранены.92 дополнительных кадра кодируют интерактивные сочетания отметок при ограничениях Figma Starter; в код их не переносить.
- StepItem расширен свойствами Show completion / Show number; добавлены ProgressSegment и EvidenceCard. Всего30 семейств /138 компонентов и вариантов.114 токенов /12 стилей. Четыре коллекции экспортированы, CSS/JSON пересобраны генератором.
- Структурные проверки затронутых экранов на390/1024/1440 и новых контейнеров на320/1920 прошли. Проверены64 перехода отметок. Выполнен визуальный просмотр плана, этапа, итога, диалога, мобильных версий и нового раздела UI kit.
- Публичный HR источник проверен по странице1 этапу6; подробности внутреннего материала не выдумывались. Его наличие в рабочем индексе не утверждается.
- React frontend реализован в codex/smena-frontend; API-подключение, проверки и ограничения реализации фиксируются отдельно в frontend/README.md. Дизайн QA не выдаётся за проверку реального корпуса или отправки почты.

## 1.1.0 — 2026-11-13

Причина: завершение флоу и перенос почтовой панели из ветки codex/mailbot в общую админку.

- 45 продуктовых экранов; ID первых18 сохранены. Убраны презентационные пояснения из экранов, добавлены внешние подписи и доска маршрутов.
- Основной пример — бронирование концертного зала. Добавлены частичный ответ, отсутствие сведений, конфликт, недостаток контекста, ошибки, полный импорт и повторная проверка после обновления базы.
- 3 новых семейства: ProcessStatus, MailWorker, MailEvent. Всего28 семейств /135 компонентов и вариантов. MailEvent имеет Row/Card; PageHeading — Show subtitle. Highlight и StepItem исправлены для узких экранов.
- Почта соответствует коммиту d1c31ce ветки codex/mailbot: enabled, reply_without_issue, senders, api_url; семь событий журнала. API интеграция и отправка писем в рамках дизайна не выполнялись.
- Токены не переименовывались и не добавлялись:111 токенов,12 стилей. Четыре коллекции переэкспортированы, CSS/JSON пересобраны генератором.
- 18 адаптивных примеров для6 типов экрана. Проверены45 экранов на390/1024/1440, дополнительно8 типов контейнера на320/1920. Найденные переносы исправлены; финальные проверки в QA. Структура45 экранов: без выходов за контейнер, необвязанных видимых цветов, текста без стиля и ошибочных адресатов переходов.
- Синхронизированы manifest, CSS, правила, карта состояния и отдельный контракт бэка. Сохранение ответов и обратная связь отмечены как необходимые доработки; фиктивных Code Connect связей нет.

## 1.0.0 — 2026-11-13

- Первая версия для передачи в разработку: 25 семейств компонентов и 107 main components/вариантов; сохранены исходные ID 18 экранов.
- Primitive → Semantic → Component aliases; отдельные Layout токены. Цвета и визуальные свойства контролов привязаны к переменным; типографика — к общим стилям.
- Добавлены состояния кнопок, полей, навигации, выбора, статусов и содержательных блоков; свойства текста и instance swap для иконок.
- Повторяемые элементы флоу заменены экземплярами UI kit. Переходы прототипа сохранены.
- Добавлены 12 примеров на 1440/1024/390px: ответ, реестр, карта и форма источника. При переходе в одну колонку сбрасывается лишний vertical Fill.
- Добавлены документация в Figma, CSS foundation, token export, manifest и правила синхронизации `AGENTS.md`.
- Финальные результаты проверок — `smena-design-qa.json`; ограничения реализации — `smena-design-system.md`.
