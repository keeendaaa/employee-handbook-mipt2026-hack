# employee-handbook-mipt2026-hack

Кейс № 4: «Навигатор сотрудника по внутренним регламентам».

Система должна находить ответ на вопрос сотрудника в предоставленных документах, формировать порядок действий и подтверждать ключевые выводы источниками.

## Документация

- [TASK.md](TASK.md) — описание задачи, ожидаемый результат, ограничения и требования к сдаче.
- [DOCUMENTS.md](DOCUMENTS.md) — перечень 20 исходных материалов с описаниями.
- [CRITERIA.md](CRITERIA.md) — полная разбалловка, план тестирования и шаблон протокола проверки.
- [AGENTS.md](AGENTS.md) — инструкции для агентов, работающих над проектом.
- [data/README.md](data/README.md) — размещение исходных материалов и границы технической проверки.
- [DATA_PUBLICATION.md](DATA_PUBLICATION.md) — результаты первичной проверки возможности публикации данных.
- [BACKEND_PLAN.md](BACKEND_PLAN.md) — исследование и предлагаемый план бэкенда; пока не реализация.
- [ARCHITECTURE.md](ARCHITECTURE.md) — схема бэкенда диаграммами: контекст, компоненты, ingest, поток ответа, модель данных, развёртывание.

## Текущий статус

Сохранены условия кейса и правила разработки. Локально загружены все 20 исходных файлов в `data/raw/`, реестр загрузки — `data/manifest.json`. Эти данные исключены из Git до подтверждения разрешения на публикацию и не входят в клонируемый репозиторий.

Выполнен первичный скрининг данных; разрешение на перепубликацию не подтверждено.

Реализован первый этап бэкенда: локальное чтение PDF/DOCX/XLSX, OCR, E5 embeddings, PostgreSQL + pgvector, атомарные поколения индекса и поиск фрагментов (dense + русский FTS + RRF). Инструкция запуска, проверки и ограничения — в [INGEST.md](INGEST.md). Добавлены HTTP API, страница с открытием цитат по строкам и генерация через внешний Qwen 27B. Автоматическое разрешение редакций и сопровождение состояния процедуры пока не реализованы. Запуск и ограничения — в [DEPLOY.md](DEPLOY.md).

Поиск поддерживает длинные и составные вопросы, соседний контекст, проверяемые цитаты со строками и повторную индексацию без OCR. Проверочный набор, метрики и контракт открытия источника — в [RETRIEVAL.md](RETRIEVAL.md).
