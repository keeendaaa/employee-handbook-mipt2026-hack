# Запуск демонстрации

Фактический профиль: CPU `intfloat/multilingual-e5-small` (384 измерения, фиксированная ревизия в `embedding.py`), PostgreSQL 17 + pgvector, FastAPI и внешний `Qwen/Qwen3.8-27B` через Command Code. Веса Qwen на VPS не скачиваются. Локальный Qwen 8B остаётся вариантом развития, в этой конфигурации он не запускается.

Рекомендуемые ресурсы для текущего комплекта: 4 vCPU, 8 ГБ RAM, от 15 ГБ свободного диска; GPU не нужен. Нужен интернет для сборки, загрузки E5 и вызовов API. Инференс эмбеддингов после скачивания работает офлайн. API модели оплачивается отдельно.

## Подготовка

Установите Docker с Compose v2. Скопируйте `.env.example` в `.env`, задайте уникальный пароль PostgreSQL из букв и цифр. Для CLI вне контейнера укажите тот же пароль в `DATABASE_URL`. Секреты и материалы не входят в Docker-образ.

```sh
mkdir -p secrets data/raw data/processed models
chmod 700 secrets
# Запишите ключ Command Code в secrets/llm_api_key редактором, без помещения в историю shell.
chmod 600 secrets/llm_api_key
chmod 600 .env
docker compose build
docker compose up -d postgres
docker compose run --rm ingest download-model
docker compose run --rm ingest db-init
```

Поместите разрешённые к обработке PDF/DOCX/XLSX в `data/raw/`. Не отправляйте конфиденциальные документы во внешний API без разрешения. `data/manifest.json` необязателен для нового комплекта; для исходного комплекта используйте его при импорте для сохранения идентификаторов.

```sh
docker compose run --rm ingest ingest --manifest data/manifest.json --allow-warnings
# Для произвольного комплекта без manifest: ingest --allow-warnings
# --allow-warnings допускает неполное извлечение, сохраняя предупреждения в отчёте.
# Изучите data/processed/report.json перед демонстрацией.
docker compose up -d api
curl --fail http://127.0.0.1:8000/health/ready
```

Для VPS установите `HTTP_BIND=0.0.0.0` и `HTTP_PORT=80` в `.env`. Страница доступна по адресу сервера. Это HTTP-демонстрация; для HTTPS нужен отдельный прокси и сертификат. PostgreSQL публикуется только на loopback `127.0.0.1:5433`.

### Домен и HTTPS на VPS

Конфигурация Caddy находится в `misc/deploy/Caddyfile`: основной домен `smena-mipt.ru`, перенаправление с `www.smena-mipt.ru` и сохранение HTTP-доступа по IP. Для обоих имён нужны DNS-записи A со значением `178.20.47.178`.

При использовании прокси задайте в закрытом `.env` `HTTP_BIND=127.0.0.1`, `HTTP_PORT=8000`. Узнать шлюз Docker-сети можно командой `docker inspect navigator-api-1 --format '{{range .NetworkSettings.Networks}}{{.Gateway}}{{end}}'`; это значение укажите в `FORWARDED_ALLOW_IPS` (на текущем VPS — `172.18.0.1`). Приложение доверяет заголовкам адреса клиента только от этого шлюза, чтобы лимиты запросов различали посетителей. Порт приложения публикуется только на loopback.

На VPS, из корня проекта:

```sh
sudo apt-get install -y caddy
sudo install -m 644 misc/deploy/Caddyfile /etc/caddy/Caddyfile
sudo caddy validate --config /etc/caddy/Caddyfile
docker compose up -d api
sudo systemctl enable --now caddy
# После изменения конфигурации:
sudo systemctl reload caddy
```

Снаружи должны быть доступны TCP 80 и 443. Caddy [автоматически получает и обновляет сертификаты](https://caddyserver.com/docs/automatic-https) после публикации DNS. Добавление записей в панели регистратора само по себе ещё не подтверждает доступность домена: проверяйте публичное разрешение имён и HTTPS без отключения проверки сертификата.

Если извлечение уже выполнено этой версией кода, его можно проверить и индексировать без повторного OCR:

```sh
docker compose run --rm ingest index --report data/processed/review-v2/report.json --input data/raw --allow-warnings
```

Оригиналы должны совпадать с SHA-256 отчёта. Новые файлы добавляются повторным `ingest`, без изменения кода. Ссылки на старые поколения сохраняются.

## API и проверка

- `GET /` — страница вопроса, ответа, шагов и источников.
- `GET /health/live` — процесс запущен.
- `GET /health/ready` — доступен активный индекс; `generation_configured` сообщает только о настройке генерации, а не о текущем балансе или доступности внешнего API.
- `POST /api/search` — `{"question":"…","limit":10}`, поиск без вызова LLM.
- `POST /api/ask` — такой же запрос, ответ `answered/partial/not_found/needs_clarification/conflict`, утверждения и шаги с `citation_ids`, канонические `citations`, фактическая модель и расход токенов.
- `GET /api/sources/{source_id}` — точная цитата и полный извлечённый блок с координатами. Строки относятся к извлечённому блоку, а не к строкам оригинального PDF. OCR-пункты не считаются проверенными.

Каждое утверждение должно ссылаться на существующие источники. Сервер проверяет структуру и идентификаторы и берёт цитаты из индекса; смысловое соответствие оценивает Qwen, поэтому ссылка сама по себе не гарантирует истинность вывода. Отсутствующий ответ и техническая ошибка различаются. Существующие предупреждения извлечения, актуальность редакций и полнота процедуры требуют отдельной оценки.

Для воспроизводимого синтетического примера создайте файлы командой `uv run python code-samples/make_documents.py` по инструкции `INGEST.md` и спросите про тестовое правило, действительно записанное в файле. Два сценария на реальном разрешённом комплекте: вопрос о сроке подачи служебной записки для бронирования концертного зала → срок с цитатой и оговоркой о найденных исключениях; вопрос о первой линии техподдержки → разрешённые каналы обращения с цитатами. Содержание ответа проверяется по фактически загруженным редакциям, а не задаётся в коде.

Один процесс API обслуживает по одному поиску и генерации одновременно. Лимит публичной демонстрации: 15 попыток генерации в час на IP и 60 в час на процесс; перезапуск сбрасывает счётчики. Поиск доступен без LLM. Qwen использует `reasoning_effort=low`, лимит вывода 10000 токенов (включая рассуждение). Таймаут одного запроса к модели 120 секунд, при некорректном формате или временной HTTP-ошибке 500/502/503/504 возможна ещё одна попытка (всего не более двух вызовов). Данные и ключ не отправляются в браузер; тексты запросов не пишутся в access log.

Оценка стоимости для `Qwen/Qwen3.8-27B`: $0.40 за миллион входных и $3 за миллион выходных токенов, без скидок кэша; `usage.cost_usd_estimate` — оценка, не счёт провайдера. Тариф необходимо перепроверять у [Command Code](https://commandcode.ai/models/qwen3-8-27b).

```sh
uv sync --frozen
uv run pytest -q
# Интеграционные тесты БД: TEST_DATABASE_URL=… uv run pytest -q
# Остановка без удаления данных:
docker compose down
# Обновление кода:
docker compose build api
docker compose up -d api
```

Не выполняйте `down -v`, если требуется сохранить индекс. Для резервирования нужны `pg_dump`, оригиналы, отчёты извлечения и веса E5; ключ и `.env` хранятся отдельно с закрытыми правами.

Проверка опубликованного HTTP-сервиса без вывода содержимого документов:

```sh
uv run python misc/scripts/smoke_http.py http://127.0.0.1:8000 --question 'Ваш вопрос'
# --ask дополнительно вызывает платную генерацию и проверяет все возвращённые ссылки.
```
