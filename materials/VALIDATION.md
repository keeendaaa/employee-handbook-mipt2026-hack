# Наблюдаемая проверка 13.11.2026

## Локальные проверки

На macOS arm64, Python 3.12, с PostgreSQL прошли **74 теста**. Проверены извлечение, индексирование, поколения корпуса, сохранность старых цитат, составной поиск, валидация HTTP-запросов, структура ответов, ссылки, обрыв генерации, учёт обеих попыток и временные ошибки провайдера.

До сбоя провайдера выполнены пробные локальные прогоны десяти вопросов реального комплекта: шесть ответов `answered`, два `partial`, два `not_found`. Все возвращённые ссылки открылись и совпали с каноническими цитатами. Один составной вопрос получил `partial`, поскольку найденные фрагменты не подтверждали запрошенный год редакции. Это не полная автоматическая оценка смысловой правильности и не официальная оценка жюри.

Отдельные синтетические проверки: Qwen проигнорировал инструкцию внутри документа и показал конфликт двух одновременно действующих тестовых положений. Эти примеры не доказывают устойчивость ко всем атакам или полноту анализа настоящих редакций.

## VPS

Развёрнуто на Linux amd64, Ubuntu 26.04, 4 vCPU, около 7.4 ГБ RAM. Docker Compose запускает PostgreSQL и FastAPI. На VPS проверены оригиналы по контрольным суммам и заново вычислены E5 embeddings из ранее извлечённых артефактов. OCR повторно на VPS не запускался.

Опубликованы **20 документов и 2923 фрагмента**. Ключ корпуса совпал с локальным:

```text
bbf070c2c79be485b3cf278fe815e415d85b5d2ab0e52461e49a66874fc3d8a6
```

По внешнему HTTP-адресу прошли readiness, поиск и проверка точного совпадения источников и координат. Контрольная сумма модуля генерации внутри контейнера совпала с исходником. В браузере через SSH-туннель к VPS проверены поиск, открытие подсвеченных строк, показ технической ошибки модели и мобильная ширина 390 px без горизонтальной прокрутки. Прямой переход браузера на внешний IP был заблокирован средой проверки; HTTP-проверки этого адреса выполнены отдельно.

## Ограничения на момент проверки

- В исходном извлечении 11 документов имеют предупреждения: OCR, сложные PDF-таблицы, непроверенные сохранённые значения формул и повреждённая ссылка Excel. Это частичный успех извлечения, а не полная обработка без потерь.
- Qwen вызывается как `Qwen/Qwen3.8-27B` через Command Code; локальный Qwen 8B на VPS не запущен. E5 работает на CPU внутри VPS.
- При финальной проверке генерации Command Code возвращал **HTTP 503 `overloaded_error`** как с Mac, так и с VPS, на обоих документированных endpoint. Рабочий ответ Qwen через опубликованный VPS на этот момент не подтверждён. Сервис выполняет одну повторную попытку и возвращает явную техническую ошибку HTTP 502; поиск остаётся доступным.
- Идентификаторы и текст цитат проверяются программно; смысловое соответствие вывода источнику оценивает модель. Автоматическое разрешение редакций и независимая проверка всех процедур не выполнены.
- Демонстрация опубликована по HTTP. Данные, пароль PostgreSQL и ключ API исключены из Git и Docker-образа; оригиналы размещены на VPS по разрешению пользователя.

Инструкция повторения: [DEPLOY.md](DEPLOY.md). Для внешней проверки используйте `uv run python misc/scripts/smoke_http.py http://178.20.47.178 --question 'Ваш вопрос'`; флаг `--ask` дополнительно проверяет генерацию и расходует API-кредиты.

После завершения локальных проверок API, PostgreSQL, временные браузеры и SSH-туннель остановлены, Docker Desktop выключен. Данные PostgreSQL сохранены в volume.

## Повторная проверка: кампус, подтверждения дат и HTTPS

После добавления пользовательского словаря корпусов на Linux amd64 с отдельной тестовой PostgreSQL прошли **98 тестов**. Тестовая база после проверки удалена; основная база не очищалась. Проверены исходный и раскрытый запросы, защита от раскрытия обычной цифры/сочетаний «НК РФ» и «ГК РФ», неизменность цитат, вводные положения и даты в раздельных блоках DOCX.

Выполнен полный внутренний прогон 35 вопросов, затем дополнительная проверка 9 вопросов, затронутых восстановлением дат из шапок документов:

| Этап | Вопросы | Технические ошибки | Проверены канонические цитаты | Совпадение ожидаемого типа |
|---|---:|---:|---:|---:|
| Полный прогон после исправления генерации | 35 | 0 | 35 | 34 |
| Дополнительная проверка вопросов о датах | 9 | 0 | 9 | 9 |

В полном прогоне все 33 вопроса с эталонными источниками получили цитаты с ожидаемыми фрагментами. Оставшееся расхождение относилось к частичному ответу без календарной даты подписания: после добавления отдельной цитаты из шапки DOCX этот вопрос прошёл дополнительную проверку. Цитирование эталонного фрагмента само по себе не доказывает полноту и смысловую правильность каждого вывода.

Дополнительный автоматический оценщик проверил первый прогон. При разборе его пометок обнаружены и исправлены неподтверждённый вывод об отсутствии отдельного оформления и использование тематической статьи расходов как доказательства отсутствия тарифа во всей базе. Отдельно исправлен поиск даты введения регламента на первой странице. Пометки о номерах пунктов и заголовках Excel разбирались по источникам: автоматическая оценка не считается окончательным вердиктом. В частности, оговорка о первой непустой строке I1 не отменяет непосредственно прочитанные значения F11–I11.

Домен `smena-mipt.ru` опубликован в DNS. Caddy получил публичные сертификаты для основного имени и `www`; перенаправление с `www` проверено. По HTTPS прошли readiness, поиск и открытие точных источников. В реальном браузере на HTTPS проверены подсветка строк, отсутствие ошибок JavaScript и мобильная ширина 390 px без горизонтальной прокрутки. Локальный Docker для этих проверок не запускался; тестовый браузер закрыт.

Отчёты с вопросами и текстами источников сохранены вне Git в `data/review/eval/` на VPS. Настроенный API используется только для разрешённого пользователем неконфиденциального комплекта. Предоставленные экспертом требования к оценке отражены в [CRITERIA.md](CRITERIA.md), четыре сценария демонстрации — в [DEMO.md](DEMO.md). Независимая отраслевая и официальная оценка этими проверками не заменяется; ограничения OCR и непроверенных формул сохраняются.

## Проверка импорта файлов и публичных ссылок (13 ноября 2026)

Из публичного репозитория клонирован коммит `6e542fc`; без ручной правки исходников собран Docker-образ и запущен отдельный Compose-проект с новой PostgreSQL. Использовались ранее скачанные и проверяемые по контрольным суммам веса E5 и отдельно подключённый ключ API. Повторное скачивание весов в этом прогоне не проверялось. На Linux прошли **119 тестов**, включая проверку очереди с арендой, восстановления после сбоя, запрета записи устаревшим обработчиком и атомарного дополнения снимка с повторным использованием векторов.

Синтетические материалы были отделены от рабочего корпуса. Проверены следующие сценарии:

- Публичная ссылка на PDF W3C: файл скачан и проиндексирован; предупреждения OCR сохранены, статус частичного успеха не скрыт. Повторный импорт не изменил снимок и сохранил предупреждения.
- Загрузка DOCX через HTTP: новые положения найдены, сгенерированный ответ содержит два подтверждённых действия. Все ссылки открывают точный исходный текст и совпадающие координаты.
- Повторная загрузка идентичных байтов не создаёт дубль. Повреждённый PDF получает ошибку, активный индекс остаётся прежним.
- Изменённый одноимённый DOCX отклоняется без разрешения обновления. После явного разрешения новый текст доступен поиску, прежняя цитата продолжает открываться. Ранее загруженные документы остаются доступными.
- В реальном Chrome файл загружен через форму; проверены обязательное подтверждение неконфиденциальности, отображение ошибки ссылки, восстановление статуса после перезагрузки и доступность нового документа из другого браузерного контекста.
- На ширине 390 px проверены отсутствие горизонтальной прокрутки и открытие подсвеченных строк загруженного документа. Ошибок JavaScript не зарегистрировано.

Тестовый Compose-проект, его отдельный volume PostgreSQL, контейнеры и временный checkout удалены. Отчёт с ответами и статусами сохранён вне Git в `data/review/import-check.json` на VPS. Эти проверки подтверждают механизм добавления, но не заменяют оценку извлечения произвольных сканов и сложных таблиц. Открытые ссылки Google Drive/Docs/Sheets проверены преобразованием URL в тестах; живой импорт из этих сервисов в этом прогоне не выполнялся.

После проверки на основном VPS обновлены API и `import-worker`, предварительно сохранены дамп PostgreSQL, исходники и прежний образ API для отката. По HTTPS проверены новая панель загрузки, поиск, генерация подтверждённого ответа и открытие всех его источников. В Chrome повторно проверены панель, подсветка строк и мобильная ширина без ошибок JavaScript. Исходные **20 документов** и ключ активного корпуса не изменились; тестовые файлы в рабочую базу не добавлялись. Обработчик подтверждает доступность heartbeat в PostgreSQL. Запуск и остановка описаны в [DEPLOY.md](DEPLOY.md).
